# AI ให้เลขเด็ด

เว็บแอปมือถือสำหรับวิเคราะห์เลขเพื่อความบันเทิงและความเชื่อส่วนบุคคล ออกแบบด้วยธีมม่วง–ทอง ตัวอักษรขนาดใหญ่ และเมนูหน้าแรก 6 รายการ

## ฟังก์ชันที่มีแล้ว

- เลขประจำวันจากวันที่และวันในสัปดาห์
- เลขความฝันจากพจนานุกรมสัญลักษณ์
- วิเคราะห์ความถี่เลขจากข้อความ Social ที่ผู้ใช้นำมาวาง
- เลขจากสูตร AI จำลองโดยผสานข้อมูลของผู้ใช้
- บันทึกเลขจากวัดพร้อมชื่อสถานที่ จังหวัด และแหล่งที่มา
- โปรไฟล์และดวงเลขสมาชิก
- บันทึกประวัติ แชร์ผล และเก็บข้อมูลไว้ในอุปกรณ์ด้วย localStorage
- PWA พร้อม manifest และ service worker

## เริ่มใช้งานในเครื่อง

```bash
npm install
npm run dev
```

ตรวจ smoke test:

```bash
npm test
```

## ขอบเขตเวอร์ชันนี้

ระบบ Social เป็นการวิเคราะห์ข้อความที่ผู้ใช้นำมาวาง ยังไม่ได้เชื่อม API เพื่อดึงข้อมูลสด และข้อมูลเลขจากวัดเป็นข้อมูลที่ผู้ใช้บันทึกเอง ระบบไม่สร้างข่าวหรืออ้างแหล่งที่มาแทนผู้ใช้

ผลลัพธ์ทั้งหมดไม่มีการรับรองความแม่นยำและไม่ควรใช้แทนการตัดสินใจทางการเงิน
